# MultiMediaPlayer · 多画面媒体播放器

Windows 11 x64 本地播放器。把视频和静态图片拖到同一个窗口，最多显示九个画面。自动适配按素材实际显示比例选择布局。默认完整显示，也可以单独选择居中裁切铺满。

## 使用

1. 解压 `MultiMediaPlayer-win-x64.zip`，运行目录内的 `MultiMediaPlayer.exe`。请保留解压目录中的其他文件。
2. 点击「添加媒体」、按 `Ctrl+O` 或拖入本地文件。新导入的视频默认循环播放，选中视频发声。暂停选中视频后保持安静，恢复时继续发声；选中图片、无音轨视频或启用总静音时所有视频静音。
3. 点击画面切换控制目标。拖动标题到另一画面的上、下、左、右边缘可重新分区，拖到中央可交换位置。也可右键标题，选择目标画面及方向。拖动分隔线修改比例，双击分隔线可输入 `60:40` 这样的数值。点击「自动适配」可重新优化分区。
4. 选中视频后，在画面中按 `←` / `→` 快退或快进 5 秒，按住 `Shift` 跳转 30 秒。选中图片后，`←` / `→` 切换同目录的上一张／下一张图片。按住 `Ctrl` 滚动滚轮，或用底部按钮，以 25 个百分点为一档缩放画面。放大后按住左键拖动查看，点击「重置」恢复 100% 并居中。
5. 「主画面 + 辅助」将当前选中画面放进 60% 的主分区。`F11` 切换全屏，`Esc` 退出全屏。底部可调整速度、进度、显示模式和解码方式。
6. 用「保存工作区」记住媒体路径、布局、缩放、平移和进度。打开 `.mmp.json` 后视频保持暂停。媒体移动后可通过「重新定位」更新路径。

图片支持 JPEG、PNG、WebP、BMP。视频常用容器包括 MP4、MOV、MKV、AVI、WebM，实际编码支持由随包附带的 LibVLC 决定。首版按静态图展示图片。超过 8000 万像素的图片显示错误提示，显示缓存长边最多 4096 像素。

图片画面选中、悬停或获得键盘焦点时，底部显示前后切换、序号和「⋯ 管理图片」入口，全屏同样可用；小画面将序号收进提示。默认浏览同目录的图片，按文件名自然排序（图1、图2、图10），不包含子目录，也不会首尾循环。目录在窗口重新激活、打开管理窗口或发现文件失效时刷新。

「管理图片」使用独立窗口。点击「创建自定义图片集」后，可以多选添加图片、批量添加文件夹（可包含子目录）、多选移除和上移／下移。新添加的批次自然排序并追加，重复完整路径只保留一项；不同画面允许使用相同图片。自定义集不随文件夹自动变化。点击「应用」统一提交，取消或关闭窗口丢弃草稿；「切回目录浏览」也只在应用后生效。移除只影响图片集，不删除文件，至少保留一项。

翻图保持各画面的分区位置和显示模式，缩放恢复 100% 并居中；点击「自动适配」可按新图片比例重新优化布局。坏图或缺失文件会跳过并提示，没有可用图片时保留原画面。自定义集保留失效记录，方便重新定位或移除。工作区保存图片集顺序和当前图片；目录浏览只保存当前图片路径。

声音跟随系统默认播放设备。插拔耳机或切换默认输出后会自动恢复，保留声音目标、音量及暂停状态。暂时没有可用设备时显示「等待音频输出设备」，视频继续播放。音频输出恢复失败会单独提示。

## 构建和验证

需要 Windows x64 和 .NET 10 SDK 10.0.403 或同系列更新补丁，发布脚本需要 PowerShell 7。构建无需预装 VLC。本工作区已在 `.tools/dotnet/` 放置 SDK，可将以下命令中的 `dotnet` 换成 `.\.tools\dotnet\dotnet.exe`，发布脚本会自动识别它。

```powershell
dotnet build MultiMediaPlayer.slnx -c Release
dotnet run --project tests/MultiMediaPlayer.Tests -c Release
pwsh -File scripts/audio-fixtures.ps1
dotnet run --project tests/MultiMediaPlayer.AudioTests -c Release
pwsh -File scripts/publish.ps1
```

发布脚本生成 `artifacts/MultiMediaPlayer-win-x64.zip` 和对应目录，包含 .NET 桌面运行库、LibVLC 和 SkiaSharp。用于复现功能测试和性能测试的命令见 `VALIDATION.md`。

源码按纯布局与工作区模型、WPF 界面、媒体服务拆分。新保存的工作区使用版本为 2 的 JSON，支持读取版本 1；1.0.x 播放器不能打开版本 2 工作区。工作区上限 2 MiB，超限保存会提示并保留原文件。日志保存在 `%LOCALAPPDATA%\MultiMediaPlayer\player.log`，只写本机。

音频固定使用 DirectSound 的独立播放器缓冲区，输出为 PCM；不启用数字音频直通。音频集成测试使用 NAudio 的 WASAPI 进程回环采集实际输出，依赖测试主机的默认播放设备，NAudio 不进入播放器发布包。无设备或无法采集时测试报告「未验证」，不计为通过。
